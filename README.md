# MOVIA

**Clinical Intelligence for Physiotherapy**

MOVIA is a web-based clinical workflow platform for physiotherapy assessment, treatment planning, exercise selection, progress tracking and reporting.

## Pilot

Designed for the St. Andrews College of Physiotherapy (SACOP OPD) pilot. The current V1 uses **synthetic demonstration patient data only**.

## V1 includes

- Clinician login/demo entry
- Dashboard and patient caseload
- Patient profiles
- Subjective and objective assessment workflow
- MOVIA clinical decision-support screen
- Treatment planning
- Exercise library / HEP actions
- Progress tracking
- Clinical report generation/printing
- Pilot feedback capture

## Important

This V1 is a workflow prototype and decision-support interface. It is not an autonomous diagnostic system. Clinical decisions remain with the treating physiotherapist.

## Run locally

Open `index.html` in a modern browser. No build step is required for this V1.

## Deployment

The repository can be deployed as a static site using GitHub Pages or Vercel. Future versions can add a secure backend, authentication, database, audit trail and reviewed AI services.
